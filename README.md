## Install

1. Download the `.rtz` file from the [latest release](../../releases/latest).
2. Copy it to `%LOCALAPPDATA%\DK64Recompiled\mods`.
3. Start or restart Recompiled.

## If you want to help:

- If you see missing HD textures you can enable the dev mod in:

    %USERPROFILE%\AppData\Local\DK64Recompiled\graphics.json 

- modify the line

    "developer_mode": false,

- to

    "developer_mode": true,

- Now in game you can use F1 and go on texture  -> Start dumping textures -> chose the folder to save the dump and just play the game.
- You can upload the dump file and post in [issues](../../issues)
